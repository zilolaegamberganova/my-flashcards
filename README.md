# 🗂️ Flashcard Project

Interactive web application designed to help users learn and memorize information effectively using flashcards. Built with clean and modern frontend technologies.

## ✨ Features
- **Interactive Cards:** Flip through cards easily to test your knowledge.
- **Modern UI/UX:** Clean, responsive, and user-friendly interface.
- **Easy Navigation:** Smooth transitions and intuitive controls for learning.

## 🚀 Tech Stack
- **HTML5** — Structure and content
- **CSS3** — Styling, layout, and animations (Flexbox/Grid)
- **JavaScript** — Interactivity and dynamic logic
